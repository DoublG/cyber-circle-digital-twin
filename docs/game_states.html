Cyber Circle Challenge game states

How the game moves from an empty room to rounds, the scoreboard and exterminations. From game_manager.gd and arena.gd. All times are in the web interface (Instellingen) and divided by the tempo.

Mode: set by the operatorState: the game loopRuns in parallel

1. Operator modes

Set from the web interface (MQTT mode). Without a control server the game starts OPEN. Players can only join while OPEN.

flowchart LR
  SETUP["SETUP
tiles and screens assigned
screens show slot numbers"]
  CLOSED["CLOSED
setup locked
no players"]
  OPEN["OPEN
players join
rounds start by themselves"]
  PAUSED["PAUSED
timers and tile games frozen"]
  SETUP <--> CLOSED
  CLOSED <--> OPEN
  SETUP <--> OPEN
  OPEN -- "pause" --> PAUSED
  PAUSED -- "resume" --> OPEN
  OPEN -. "to SETUP / CLOSED:
game stopped, results saved,
invites cancelled" .-> CLOSED

2. The game loop

Four states: LOBBY, INTRO, PLAYING, SCOREBOARD. Lives only change on the scoreboard. Players who join during a round wait and come in at the next scoreboard as NIEUW.

flowchart TD
  L(["LOBBY
idle, nobody playing"])
  J{"first player activates
a tile (mode OPEN)"}
  N["next round
randomizer picks a type
(weights, drought, lives director)"]
  E{"any players left?"}
  F["finish game
results + ranks saved,
everyone leaves"]
  I["INTRO
shared screens: title + rules
intro_time 7 s"]
  P["PLAYING"]
  PS["shared round (quiz)
one screen for all"]
  PP["personal round
split views per player
late joiners: WACHT OP DE VOLGENDE RONDE"]
  X{"round over?
time up, all out, or skip"}
  R["end of round
lives plan (+1 / 0 / -1)
robot already turns to the first doomed"]
  RT["personal: places in own view
result_time 10 s"]
  S1["SCOREBOARD
lives as they were
new players NIEUW"]
  S2["lives revealed after lives_delay 2.5 s
+1 green, -1 robot fires,
0: GEËXTERMINEERD banner"]
  S3["scoreboard_time 8 s"]

  L --> J --> |"auto_start_delay 20 s"| N
  N --> E
  E -- "no" --> F --> L
  E -- "yes" --> I --> P
  P --> PS & PP
  PS --> X
  PP --> X
  X -- "no" --> P
  X -- "yes" --> R
  R -- "personal" --> RT --> S1
  R -- "shared" --> S1
  S1 --> S2 --> S3 --> N
  STOP["Stop spel"] -.-> F

3. Extermination (on top of the loop)

Starts when the scoreboard reveals 0 lives. It never holds up the next round. Several players are exterminated together; the robot moves from one to the next.

flowchart TD
  D["lives reach 0 on the scoreboard
all doomed players at once"]
  B["tile blinks red
overview: popup over the floating camera"]
  H["robot turns and fires
(the next doomed one while this one plays)"]
  A["tile death animation
electrocution + explosion + free_delay"]
  W{"player's own split view
on screen?"}
  C["death clip from the start
shorter than clip_time: last frame held"]
  T{"waited longer than
clip_wait 30 s?"}
  FREE["tile free again"]
  D --> B --> H --> A
  H --> W
  W -- "yes" --> C
  W -- "no (shared screens)" --> T
  T -- "no, keep waiting" --> W
  T -- "yes, skip clip" --> FREE
  C -- "after clip_time 8 s
(or the clip, if longer)" --> FREE
  A --> FREE

The tile is freed when both the death animation and the clip (or its wait) are done.
